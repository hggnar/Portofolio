# Portfolio Website – Rangga Ho

Website portofolio pribadi yang dibuat untuk memperkenalkan diri, keahlian, dan sertifikat saya sebagai mahasiswa Teknik Informatika di Universitas Gunadarma. Desainnya dibuat di Figma, lalu diubah menjadi website interaktif dengan HTML, CSS, dan JavaScript.

## Fitur

- Halaman satu layar yang terdiri dari Home, About, Skills, Certificate, dan Contact
- Menu navigasi tetap di atas, dengan scroll halus dan penanda otomatis untuk bagian yang sedang dilihat
- Tampilan responsif untuk komputer, tablet, dan HP
- Sertifikat yang bisa diperbesar dengan sekali klik
- Tautan kontak ke email, LinkedIn, dan GitHub

## Teknologi

- **HTML5** untuk struktur halaman
- **CSS3** untuk tampilan (Flexbox, Grid, dan ukuran fleksibel dengan `clamp()`)
- **JavaScript** untuk interaksi (navigasi aktif dan popup sertifikat)
- **Figma** untuk perancangan desain
- Font **Ubuntu** dari Google Fonts

## Struktur Project

```
Portofolio/
├── index.html    # struktur dan isi halaman
├── style.css     # tampilan dan layout
├── script.js     # interaksi
└── images/
    ├── photo.png
    └── certificate.png
```

## Cara Menjalankan

1. Download atau clone repository ini.
2. Buka folder project di VS Code.
3. Klik kanan `index.html`, lalu pilih **Open with Live Server** (ekstensi Live Server).
   Atau, buka `index.html` langsung di browser.

Tidak perlu instalasi tambahan. Koneksi internet hanya dibutuhkan untuk memuat font.
